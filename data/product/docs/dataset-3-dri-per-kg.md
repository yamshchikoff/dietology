# Датасет 3: DRI Макронутриенты на кг массы тела

Диетические референсные значения Ca, P, Mg в мг/кг массы тела. 51 группа.

**Источник:** MSD Manual / IOM 1997
**Уровень:** A — машинно-извлечено

## Нутриенты (3)

Calcium, Phosphorus, Magnesium — все в **мг/кг**

## Группы (17 на нутриент)

Разбивка по жизненным стадиям аналогично датасету 1 (Минералы), но консолидирована в per-kg значения.

## КРИТИЧЕСКОЕ СОГЛАШЕНИЕ

**Все значения — мг/кг массы тела.** Инструмент возвращает per-kg значения как есть, без умножения.

Ты обязан умножить значение на фактическую массу тела индивида:
```
абсолютное потребление (мг) = value (мг/кг) × масса тела (кг)
```

Эти значения точнее для индивидуального применения, чем фиксированные абсолютные DRI.

Младенцы: AI. Дети и взрослые: RDA.

## Возвращаемые поля

- `value` — значение в мг/кг (число)
- `type` — "RDA" или "AI"
- `unit` — всегда "mg/kg"

## Describe-инструмент

**`describe_dri_per_kg()`** — без параметров. Возвращает: `nutrients[]` (3 имени), `groups[]`, `unit` = "mg/kg". Вызови, если не знаешь точный ключ nutrient или group.

## Инструмент

**`query_dri_per_kg(nutrient, group)`**

Параметры-фильтры (все опциональны, кроме nutrient):
- `nutrient` (str) — "Calcium", "Phosphorus" или "Magnesium". **Обязателен.**
- `group` (str | None) — фильтр по группе, например "males_19_30yr"

Возвращает массив записей, подходящих под фильтры. Не забудь умножить value на массу тела.
