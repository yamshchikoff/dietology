Все 6 случаев — подтипы/подгруппы тестов без собственной единицы измерения (inherit от родительского теста через `prev_unit`). Не баг.

### Нечисловые значения (25 lower, 27 upper) — по дизайну

Lower/upper — строки, могут содержать нечисловые значения вроде `<0.5`, `≥1.0`, возрастные диапазоны, комбинированные значения. Это задокументировано в `dataset-9-lab-ranges.md`: «может быть нечисловым значением вроде '<0.5'». Не баг.

### Null lower (68) — легитимные

68 записей без нижней границы — тесты, где референсный диапазон определяется только верхней границей (напр. `<X` пороги для антител, опухолевых маркеров).
