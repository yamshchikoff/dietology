## Методологическое ограничение

**Только машиночитаемые источники.** Исключены:
- Сканированные PDF, требующие OCR — ошибки распознавания числовых значений недопустимы в медицинском контексте.
- Нарративные PDF, требующие NLP/LLM-экстракции структурированных данных — риск галлюцинаций и неверной интерпретации.
- Данные, требующие ручного переноса (copy-paste) из неструктурированных источников — human error.

Допустимы: JSON, CSV, XML, HTML-таблицы, Parquet, структурированный викитекст. Born-digital PDF с текстовым слоем и машинно-извлекаемыми таблицами — допустимы после валидации извлечённых значений.

## Tier-система надёжности

| Tier | Критерий | Пример |
|------|----------|--------|
| **A** — Авторитетный, машиночитаемый, CC0/BY | Прямая загрузка структурированных данных из первичного источника | USDA FoodData Central, WHO GHO |
| **B** — Авторитетный, машиночитаемый, извлечённый | Структурированные данные из первичного источника, извлечённые программно (HTML-таблицы, PDF-таблицы с текстовым слоем) | MSD Manual DRI tables |
| **C** — Третичный, машиночитаемый, прослеживаемый | Агрегированные данные из вторичных/третичных источников, с цитированием первичных. Пригодны для контекста, не для нормативных рекомендаций | Wikipedia reference ranges |

**D исключён** (ненадёжный/неясный источник) — модель обучена на более качественных данных, добавленная ценность отсутствует.

## Категория 1 — Нутритивные нормы и референсные диапазоны

| | |
|---|---|
| **URL** | https://fdc.nal.usda.gov/ |
| **Язык** | EN |
| **Лицензия** | CC0 1.0 Universal (Public Domain) |

| **Формат** | JSON API + CSV bulk download |

Основной источник данных о составе продуктов. Макро- и микронутриенты на 100г, включая аминокислотные профили, жирные кислоты, витамины, минералы.

Крупнейшая открытая база продуктов. Особенно полезна для брендированных продуктов с штрихкодами. Данные краудсорсинговые — качество варьируется.

MSD Manual — профессиональное медицинское руководство. Таблицы DRI содержат: макронутриенты (белок, энергия, кальций, фосфор, магний) на кг массы тела по возрастным группам; витамины (A, C, D, E, K, B1-B12, фолат) с RDA/AI/UL; минералы (Ca, Fe, Mg, P, K, Na, Zn, Cu, I, Se, Mn, Cr, Mo) с RDA/AI/UL. HTML-таблицы извлекаются программно без ошибок распознавания.

**Конкретные URL таблиц:**

### National Academies DRI — The Essential Guide — Tier B

| | |
|---|---|
| **URL** | https://www.nationalacademies.org/publications/11537 |
| **Язык** | EN |
| **Лицензия** | Бесплатный PDF (free account required). **Числовые факты не являются объектом авторского права.** |
| **MIT-совместимо** | Да (числовые значения DRI — факты) |
| **Формат** | PDF с текстовым слоем (born-digital, 2006). Summary Tables: pp. 529–542 |
| **Качество** | Первичный авторитетный источник. Золотой стандарт DRI для США и Канады. |

Полный свод DRI (RDA, EAR, AI, UL) по всем нутриентам для всех возрастных групп. Текстовый слой извлекаем, таблицы парсимы. Требуется программная экстракция + ручная валидация извлечённых значений. Обновления по отдельным нутриентам выходили в 2019 (Na, K) и 2023 (Energy).

### WHO 2024 Haemoglobin Guideline — Tier B

| | |
|---|---|
| **URL** | https://www.who.int/publications/i/item/9789240088542 |
| **Язык** | EN |
| **Лицензия** | CC BY-NC-SA 3.0 IGO |
| **MIT-совместимо** | ⚠️ NC restriction. Числовые пороговые значения — факты, но bundled таблицы из WHO PDF — вопрос интерпретации. |

Таблицы структурированы, извлекаемы. Лицензия NC — ограничение использования в MIT-проекте; числовые факты как таковые неохраноспособны, но прямое копирование таблиц невозможно.

## Категория 3 — Клинические рекомендации

### WHO SMART Guidelines (FHIR) — Tier B

| | |
|---|---|
| **URL** | https://github.com/WorldHealthOrganization/smart-base |
| **Язык** | EN |
| **Лицензия** | Софт: BSD-like. Контент: CC BY-NC-SA 3.0 IGO |
| **MIT-совместимо** | Софт-часть — да. Контент — требует проверки (NC) |
| **Формат** | JSON, XML, CQL, ELM+JSON (FHIR R4) |

Машинно-читаемые клинические руководства в FHIR-формате. Содержат decision-support логику по диетологическому консультированию (ANC Dietary Counselling и др.). **Важно:** контент под CC BY-NC-SA (non-commercial). Софтверная часть — BSD-like. При использовании в MIT-проекте: софтверные артефакты совместимы, контент требует отдельного рассмотрения.

### Три критических пробела

1. **Лабораторные референсные диапазоны — Tier A/B.** Wikipedia (Tier C) — единственный машиночитаемый компендиум. Первичные источники: MedlinePlus (public domain, но без числовых значений на страницах), клинические руководства (нарративные PDF). Авторитетного машиночитаемого компендиума lab reference ranges не существует.

2. **Пороговые значения дефицита микронутриентов (кроме Hb).** WHO публикует пороги для витамина A, цинка, йода, ферритина и др. исключительно в нарративных PDF. Гемоглобин — исключение (WHO 2024 guideline со структурированными таблицами, извлекаемыми из PDF).

3. **Клинические рекомендации по нутритивной поддержке.** ESPEN исключён (нарративный PDF). WHO SMART Guidelines — FHIR, BSD-like код, но контент NC + фокус на pregnancy (ANC Dietary Counselling), не general adult nutrition. Машиночитаемых guidelines для «нутритивная поддержка при X» не существует.

### Исключённые источники

| Источник | Причина |
|----------|---------|
| **NICE** (UK) | UK-only, non-commercial, международное использование заблокировано |
| **WHO Publications — нарративные PDF** | CC BY-NC-SA + не machine-readable |
| **ESPEN Guidelines** | Нарративный PDF, требует NLP-экстракции → риск ошибок |
| **NIH ODS Fact Sheets** | Cloudflare-блокировка (403). US government public domain, но недоступны программно. Возврат при снятии блокировки. |
| **MIMIC-IV / hospital-specific ranges** | Tier D — исключён по решению maintainer |
