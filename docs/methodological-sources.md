## Методологическое ограничение

**Только машиночитаемые источники.** Исключены:
- Сканированные PDF, требующие OCR — ошибки распознавания числовых значений недопустимы в медицинском контексте.
- Нарративные PDF, требующие NLP/LLM-экстракции структурированных данных — риск галлюцинаций и неверной интерпретации.
- Данные, требующие ручного переноса (copy-paste) из неструктурированных источников — human error.

Допустимы: JSON, CSV, XML, HTML-таблицы, Parquet, структурированный викитекст. Born-digital PDF с текстовым слоем и машинно-извлекаемыми таблицами — допустимы после валидации извлечённых значений.

## Tier-система надёжности

| Tier | Критерий | Пример |
|------|----------|--------|
| **A** — Авторитетный, машиночитаемый, CC0/BY | Прямая загрузка структурированных данных из первичного источника | USDA FoodData Central, WHO GHO |
| **B** — Авторитетный, машиночитаемый, извлечённый | Структурированные данные из первичного источника, извлечённые программно (HTML-таблицы, PDF-таблицы с текстовым слоем) | MSD Manual DRI tables |
| **C** — Третичный, машиночитаемый, прослеживаемый | Агрегированные данные из вторичных/третичных источников, с цитированием первичных. Пригодны для контекста, не для нормативных рекомендаций | Wikipedia reference ranges |

**D исключён** (ненадёжный/неясный источник) — модель обучена на более качественных данных, добавленная ценность отсутствует.

## Категория 1 — Нутритивные нормы и референсные диапазоны

### USDA FoodData Central ⭐ Tier A

| | |
|---|---|
| **URL** | https://fdc.nal.usda.gov/ |
| **Язык** | EN |
| **Лицензия** | CC0 1.0 Universal (Public Domain) |
| **MIT-совместимо** | Да |
| **Формат** | JSON API + CSV bulk download |
| **Объём** | 7,800+ Foundation Foods, SR Legacy, FNDDS, Branded Foods |
| **API** | `https://api.nal.usda.gov/fdc/v1/` (бесплатный ключ) |
| **Качество** | Авторитетный источник, U.S. government, регулярные обновления |

Основной источник данных о составе продуктов. Макро- и микронутриенты на 100г, включая аминокислотные профили, жирные кислоты, витамины, минералы.

### Open Food Facts — Tier B

| | |
|---|---|
| **URL** | https://world.openfoodfacts.org/data |
| **Язык** | Multi (включая RU) |
| **Лицензия** | ODbL 1.0 (Open Database License) |
| **MIT-совместимо** | Да (лицензия на данные, не на код) |
| **Формат** | JSONL daily export (`.jsonl.gz`), Parquet (Hugging Face), CSV, REST JSON API |
| **Объём** | 3.7+ млн продуктов |
| **Качество** | Crowdsourced, неравномерное качество, широчайший охват |

Крупнейшая открытая база продуктов. Особенно полезна для брендированных продуктов с штрихкодами. Данные краудсорсинговые — качество варьируется.

### WHO Global Health Observatory (GHO) ⭐ Tier A

| | |
|---|---|
| **URL** | https://data.who.int / https://www.who.int/data/gho |
| **Язык** | EN |
| **Лицензия** | CC BY 4.0 |
| **MIT-совместимо** | Да |
| **Формат** | CSV, JSON, XML, Excel через OData API |
| **Объём** | 1,000+ индикаторов по 194 странам |
| **Качество** | Авторитетный источник, популяционные нормы |

Референсные данные по нутритивному статусу популяций: child growth standards, malnutrition indicators, micronutrient deficiencies, breastfeeding, overweight/obesity. Полезно для контекстуализации индивидуальных показателей пользователя относительно популяционных норм.

### MSD Manual Professional — DRI Tables — Tier B

| | |
|---|---|
| **URL** | https://www.msdmanuals.com/professional (таблицы DRI для макронутриентов, витаминов, минералов) |
| **Язык** | EN, multi |
| **Лицензия** | Copyright Merck & Co. Свободный доступ. **Факты (числовые значения) не являются объектом авторского права.** |
| **MIT-совместимо** | Да (числовые факты + attribution) |
| **Формат** | HTML-таблицы (структурированные, извлекаемые программно) |
| **Качество** | Авторитетный вторичный источник. Таблицы основаны на National Academies DRI reports. |

MSD Manual — профессиональное медицинское руководство. Таблицы DRI содержат: макронутриенты (белок, энергия, кальций, фосфор, магний) на кг массы тела по возрастным группам; витамины (A, C, D, E, K, B1-B12, фолат) с RDA/AI/UL; минералы (Ca, Fe, Mg, P, K, Na, Zn, Cu, I, Se, Mn, Cr, Mo) с RDA/AI/UL. HTML-таблицы извлекаются программно без ошибок распознавания.

**Конкретные URL таблиц:**
- Макронутриенты: `https://www.msdmanuals.com/professional/multimedia/table/recommended-dietary-reference-intakes-for-some-macronutrients-food-and-nutrition-board-institute-of-medicine-of-the-national-academies`
- Витамины: `https://www.msdmanuals.com/professional/multimedia/table/recommended-daily-intakes-for-vitamins` (проверить точный URL)
- Минералы: `https://www.msdmanuals.com/professional/multimedia/table/recommended-daily-intakes-for-minerals` (проверить точный URL)

### National Academies DRI — The Essential Guide — Tier B

| | |
|---|---|
| **URL** | https://www.nationalacademies.org/publications/11537 |
| **Язык** | EN |
| **Лицензия** | Бесплатный PDF (free account required). **Числовые факты не являются объектом авторского права.** |
| **MIT-совместимо** | Да (числовые значения DRI — факты) |
| **Формат** | PDF с текстовым слоем (born-digital, 2006). Summary Tables: pp. 529–542 |
| **Качество** | Первичный авторитетный источник. Золотой стандарт DRI для США и Канады. |

Полный свод DRI (RDA, EAR, AI, UL) по всем нутриентам для всех возрастных групп. Текстовый слой извлекаем, таблицы парсимы. Требуется программная экстракция + ручная валидация извлечённых значений. Обновления по отдельным нутриентам выходили в 2019 (Na, K) и 2023 (Energy).

### WHO 2024 Haemoglobin Guideline — Tier B

| | |
|---|---|
| **URL** | https://www.who.int/publications/i/item/9789240088542 |
| **Язык** | EN |
| **Лицензия** | CC BY-NC-SA 3.0 IGO |
| **MIT-совместимо** | ⚠️ NC restriction. Числовые пороговые значения — факты, но bundled таблицы из WHO PDF — вопрос интерпретации. |
| **Формат** | PDF (born-digital, 2024). Таблицы структурированы. |
| **Качество** | Авторитетный первичный источник. Глобальный стандарт диагностики анемии. |

Новые (2024) пороговые значения гемоглобина: снижен порог для детей 6–23 мес (105 g/L вместо 110), добавлены триместр-специфичные пороги для беременных (второй триместр: 105 g/L). Таблицы структурированы, извлекаемы. Лицензия NC — ограничение использования в MIT-проекте; числовые факты как таковые неохраноспособны, но прямое копирование таблиц невозможно.

### Wikipedia — Reference Ranges for Blood Tests — Tier C

| | |
|---|---|
| **URL** | https://en.wikipedia.org/wiki/Reference_ranges_for_blood_tests |
| **Язык** | EN |
| **Лицензия** | CC BY-SA 3.0 |
| **MIT-совместимо** | Да (SA — share-alike, но числовые факты неохраноспособны) |
| **Формат** | HTML/Wikitext, структурированные таблицы. 300+ тестов. |
| **Качество** | Третичный источник. Цитирует: MedlinePlus, First Aid for USMLE, Merck Manual, Uppsala University Hospital, Mayo Clinic Laboratories, GPnotebook. |

Пригоден для контекстуализации результатов пользователя, но не для нормативных рекомендаций — референсные диапазоны вариабельны между лабораториями и методами. CC BY-SA — допустимо для MIT (SA относится к производным вики-текста, не к фактам).

## Категория 3 — Клинические рекомендации

### WHO SMART Guidelines (FHIR) — Tier B

| | |
|---|---|
| **URL** | https://github.com/WorldHealthOrganization/smart-base |
| **Язык** | EN |
| **Лицензия** | Софт: BSD-like. Контент: CC BY-NC-SA 3.0 IGO |
| **MIT-совместимо** | Софт-часть — да. Контент — требует проверки (NC) |
| **Формат** | JSON, XML, CQL, ELM+JSON (FHIR R4) |
| **Качество** | Авторитетный, machine-readable |

Машинно-читаемые клинические руководства в FHIR-формате. Содержат decision-support логику по диетологическому консультированию (ANC Dietary Counselling и др.). **Важно:** контент под CC BY-NC-SA (non-commercial). Софтверная часть — BSD-like. При использовании в MIT-проекте: софтверные артефакты совместимы, контент требует отдельного рассмотрения.

### ESPEN Guidelines — Исключено machine-readable constraint

| | |
|---|---|
| **URL** | https://www.espen.org/guidelines |
| **Язык** | EN |
| **Лицензия** | Статьи: CC BY / CC BY-NC-ND (варьируется). Сайт: All Rights Reserved |
| **MIT-совместимо** | Требует проверки конкретной статьи |
| **Формат** | PDF (нарративные, без структурированных таблиц) |
| **Качество** | Золотой стандарт клинической нутрициологии, экспертный уровень |

**Исключено:** извлечение структурированных данных из нарративных PDF требует NLP/LLM-экстракции, что создаёт риск ошибок интерпретации. Машинно-читаемые структурированные таблицы отсутствуют. Возврат к источнику — при появлении структурированной версии рекомендаций или официального JSON-дампа.

| | |
|---|---|
| **URL** | https://www.who.int/publications |
| **Язык** | EN, RU, multi |
| **Лицензия** | CC BY-NC-SA 3.0 IGO |
| **MIT-совместимо** | ⚠️ NC restriction |
| **Формат** | PDF (нарративные, не структурированные) |

**Исключено по двум причинам:** (1) NC restriction несовместим с MIT для bundled data; (2) нарративные PDF не являются машиночитаемыми. Возможно использование как внешней ссылочной базы (не bundled data).
